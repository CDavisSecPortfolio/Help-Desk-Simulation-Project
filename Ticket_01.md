**Platform:** ServiceNow

**Status:** fictional worked example; not executed.

## User report
Maya Brooks cannot sign in to her workstation. One employee is affected and work is blocked.

## Where to work
Incident > New; record caller, device, symptoms, impact and urgency.

## Procedure
1. Record Maya Brooks, LAB-PC01, start time and exact error without recording passwords.
2. Ask whether another application works, whether coworkers are affected and what changed.
3. Set category to account access. Use impact 3 and urgency 2 for this fictional one-user outage.
4. Use the configured priority matrix; this lab assumes priority 3 for that combination.
5. Assign the Service Desk group and yourself; move the ticket to In Progress.
6. Add private work notes with the diagnostic plan; give the user a plain-language update.
7. Link the account-support procedure in case 02. Resolve only after user validation; close according to the lab closure policy.
