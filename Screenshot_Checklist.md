# Capture real lab evidence
Use filenames such as `02-01-account-before.png`, `02-02-reset-options.png`, `02-03-signin-verified.png`. For each case capture (1) initial symptom or status, (2) the relevant action or configuration, and (3) the validated result or escalation. Associate each image with the actual step number, date, lab environment and ticket ID in completion-log.csv.

On Windows use Win+Shift+S. Save the PNG, inspect it, and redact private data before publishing. Never capture passwords, session codes, recovery keys, MFA QR codes, access passes, tokens or real user records. If a step cannot be run, mark it Not executed or Documentation only. A queued operation is not successful validation. Original illustrations stay in snapshots/ and must never be relabeled as live evidence.
